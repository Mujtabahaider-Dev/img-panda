== Description ==

Img Panda is a professional image optimization and SEO automation plugin for WordPress. It combines high-speed WebP conversion with cutting-edge Vision AI to ensure your website is fast, accessible, and search-engine friendly.

Beyond simple compression, Img Panda transforms your Media Library into a performance powerhouse. WebP images are significantly smaller than traditional JPEG and PNG files, while our AI SEO Suite handles the tedious task of writing descriptive Alt Text for your images automatically.

== Key Features ==

*   **AI SEO Suite**: Automatically generate descriptive Alt Text using Google Gemini or OpenAI.
*   **Automatic WebP Conversion**: Seamlessly converts images to WebP format as you upload them.
*   **Bulk Optimization**: Optimize your entire existing library with a single click.
*   **Intelligent Serving**: Detects browser support and serves WebP automatically, with fallback for old browsers.
*   **SaaS-Style Dashboard**: Monitor savings and health in a modern, high-fidelity interface.
*   **Full Backup Safety**: Always keeps a secure backup of your original images.

== Installation ==

1. Upload the `img-panda` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open the **Img Panda** dashboard to configure your quality and AI settings.
